# 🚀 Telegram Test Series Bot

Advanced Telegram Test Series Management Bot.

यह Bot Telegram पर बड़े Test Series database को manage करने,
Test upload करने, Test Index बनाने और users को Test extract
करने के लिए बनाया गया है।

---

## ✨ Main Features

### 👤 User Management

- `/start`
- User registration
- User list
- User info
- User ban
- User unban
- User activity tracking
- Paid user management

### 💎 Paid System

- Paid user list
- Add paid user
- Remove paid user
- Free trial
- Free trial lock
- Price management
- Paid user priority
